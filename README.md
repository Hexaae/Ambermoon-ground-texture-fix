# Ground texture fix for Ambermoon

Ground texture replacement for Ambermoon project (and also for the original game) by @Pyrdacor https://github.com/Pyrdacor/Ambermoon/issues/ to finally fix the "green alien vomit" ;-) broken (IMHO) texture in the original game using allegedly swapped colors palette:

<img width="1807" height="1118" alt="ground_fixed_ezgif com-gif-maker" src="https://github.com/user-attachments/assets/6b37adf1-8ba4-4686-8338-9e0f8068c1c8" />
<br>
(green = original game, grey flagstone paving = mod-fix)

### Info
The "fix" is still debatable, but some evident clues suggest that among the many little bugs of this game, also this ground texture could have been buggy... More details, if interested, in this discussion https://github.com/Pyrdacor/Ambermoon/issues/136#issuecomment-6151645749 <br>
The texture itself has not been changed, keeping the original palette and just rearranging colors for a more logical result:

### Installation
Just overwrite "Ambermoon/Amberfiles/Floors.amb" with the file "Floors.amb" in this repository, and re-launch the game.<br>
Simple as that.
